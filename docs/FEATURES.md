# 使用与验收

## 收藏与分组

侧栏打开“收藏与线路”，切换地点/线路，按分组和名称筛选。分组按钮可以新建、重命名、调整顺序和删除组。删除组仅将条目移到未分组。

点击条目打开操作菜单，支持编辑、移动分组、置顶、调整顺序、导出或删除。主地图长按位置后点击保存图标会打开收藏编辑器；历史位置长按可另存为收藏。收藏不受历史有效期清理影响，选择收藏不会直接开始模拟。

## 线路编辑与移动

侧栏“新建线路”可带入当前标记点。添加节点支持地图、搜索、手动 WGS84 坐标和已收藏地点；点击节点可以修改、删除、上移下移、断开或连接分段。填写名称、速度、循环模式并选择分组后保存。

线路至少两个节点并有有效移动距离。运行通过“保存并运行”或收藏列表“启动线路移动”触发。可在收藏页或通知中暂停/继续、停止；收藏页还可修改本次运行速度。运行中手动移动摇杆或传送到新位置会结束线路模式，防止两种模式竞争坐标。

速度范围 0～100 米/秒（不含 0）。距离按球面距离计算，播放根据单调时钟计算经过距离，可在一个周期内跨多个短线段。暂停时间不计入移动时间。达到终点后保持末端位置；循环模式回到起点重新播放。轨迹分段之间瞬间切换，不模拟跨分段连线。

当前线路为节点直连，不自动沿道路规划。编辑页面显示的是线路预览，不是实时轨迹；实际运行进度在通知和收藏页中显示。

## GPX

收藏页“GPX → 导入”调用系统选择器。支持 GPX 1.1 的 wpt、rte/rtept、trk/trkseg/trkpt；多个地点或轨迹会分别展示，可勾选要导入的条目。导入目标为当前选中的分组，“全部分组”时导入未分组。

经纬度使用 WGS84，海拔缺省为 0，时间可选。保留轨迹的分段、节点名称和有效时间戳；按设定速度播放。文件最大 8 MB，最多 10000 个节点、1000 个条目，线路需至少两个有移动距离的点。损坏数据、越界坐标、无效时间或 DTD/实体声明会拒绝导入；批次数据库写入失败时回滚。

单条导出使用条目菜单“导出 GPX”；批量导出使用“GPX → 导出当前列表”，仅导出当前地点/线路、分组及关键词筛选后的条目。系统保存对话框可选目标文件夹。导出前可取消，不需要全部文件访问权限。

## 开发版和正式版

穿梭只有标准包名 `com.chuansuo.app`。开发版可在设置的开发者工具中替换地图 Key 和控制诊断日志。正式版在构建时配置地图 Key，通过 GitHub Releases 分发。

## 自动测试与真机边界

JUnit 测试验证坐标、线路引擎与 GPX；Robolectric 验证真实 SQLite 操作和编辑页面交互，不初始化百度原生地图。构建验证开发版和正式版的包名及 FileProvider，检查正式版没有开发者配置入口。

真实地图显示、在线搜索、悬浮窗、系统位置注入仍需 ARM64 Android 设备及有效地图 Key 验收。没有这些外部条件时，不能将自动测试通过解释为已完成真机定位验证。
